# Support

Use [GitHub Discussions](https://github.com/KanadeK/dutybell/discussions) for setup questions and
workflow ideas. Use [GitHub Issues](https://github.com/KanadeK/dutybell/issues) for reproducible
bugs and narrowly scoped features. Security issues belong in private vulnerability reporting.

Before asking for help, run:

```bash
dutybell doctor --database /path/to/dutybell.db
python scripts/release_check.py --skip-build
```

Include DutyBell version, Python version, operating system, deployment command, doctor JSON, and
the smallest safe reproduction. Remove room keys, private join links, personal names, and database
contents. The project is community-supported; response times are not guaranteed.
